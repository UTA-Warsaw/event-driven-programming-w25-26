Emergency Alert System

How it works:
The dashboard contains emergency buttons. When a button is clicked, a click event is triggered. The event handler sends a POST request to the provided endpoint using JSON format.

Events:
- fire
- flood
- hurricane
- earthquake
- tornado

Event Source:
Emergency buttons

Event:
Button click

Event Listener:
JavaScript event listener

Event Handler:
Function that sends the POST request
